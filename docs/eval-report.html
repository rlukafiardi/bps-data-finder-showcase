Limits

Read the numbers with these in mind.

  • All 88 questions were written by Claude (30 from a need, 40 seeded from random catalog items, 13 with a period, 5 for the kab/kota fallback). No real user question is in the set yet, and real questions are messier.
  • Labels came from keyword filters plus pooled judging of the methods' top 5, so a correct source no method returned is not in the labels.
  • The intervals treat the 88 questions as a random sample. They are not: they describe this set only, and a difference inside the interval is noise.
  • The BPS site-search baseline was measured once, on the first 70 questions, with the same labels.
  • The rewrite is cached per question and prompt, so a rerun reproduces the numbers. A new prompt or model calls Gemini again.
